## Como anexar

- Exportar o diagrama como imagem (`.png` ou `.svg`) e salvar em `docs/casos-de-uso/diagrama.png`.
- Referenciar a imagem abaixo:

```markdown
![Diagrama de Casos de Uso](diagrama.png)
```

- Se a ferramenta salvar em formato de projeto (ex.: `.asta`, `.mdj`, `.drawio`), versionar o arquivo-fonte também nesta pasta, para permitir edição futura pelo grupo.

## Elementos que devem aparecer

- Limite do sistema (nomeado)
- Todos os atores listados em [`atores.md`](atores.md)
- Todos os casos de uso listados em [`casos-de-uso.md`](casos-de-uso.md)
- Relações `<<include>>` / `<<extend>>` com a direção correta
- Generalização entre atores, se houver
